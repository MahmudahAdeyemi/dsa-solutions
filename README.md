## Problem Structure

Each problem will have its own folder:

```text
topic/
└── problem-name/
    ├── solution.py
    └── README.md
```

The `solution.py` contains my implementation.

The `README.md` contains a short explanation of:

* The approach
* The pattern used
* Time complexity
* Space complexity
* What I learned
